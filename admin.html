Events

EventKindDateEnd dateTimeRepeatVenueStatusNoteURLShow
Date format YYYY-MM-DD; leave blank for TBA. End date only for multi-day events. Time HH:MM (24h, optional). Repeat makes the entry recur in the calendar (weekly / monthly / yearly from its date). Show: both = site + your calendar · public = site only · private = only visible while you're logged in (note: this file lives in the public repo — truly private items belong in the Private calendar below). Finished events drop off automatically.
